1. Open a request for quotation in the *RFQ* or *RFQ Sent* state.
2. Click **Import Lines**.
3. Click **Download Template** to get an empty spreadsheet with the supported
   columns. The required columns are highlighted, and each header has a
   comment that describes it.
4. Fill in one row per line, upload the file and click **Import**.

The first row of the file must hold the column names. A column is recognized
by its name in the language of the user, in English, or by its technical key
(`default_code`, `product_qty`, `name`, `price_unit`, `analytic_account`),
regardless of the case. The order of the columns does not matter.

The imported lines are added after the existing ones, and a message on the
order records the file they come from.
