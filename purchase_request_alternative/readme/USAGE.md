1. Approve a purchase request and create an RFQ from its lines
   (*Create RFQ* on the purchase request lines).
2. On the RFQ, open the *Alternatives* tab and use *Create Alternative* for
   each additional vendor, keeping *Copy Products* checked.
3. Each alternative RFQ line is linked to the same purchase request lines as
   the original one. The purchase request shows all RFQs in *Purchase Orders*.
4. Compare the RFQs with *Compare Product Lines*, choose the winning lines and
   confirm the winning RFQ. The purchase request moves to *Purchased* and the
   losing RFQs can be cancelled as usual.
