This module implements the effective_date and last_effective_date fields
in purchase order lines, allowing you to view the delivery dates.

**Table of contents**

.. contents::
   :local:

Installation
============

To see field "Effective date" and "Last Effective date" you can install
*purchase_order_line_menu*

Configuration
=============

No configuration is required.

Usage
=====

To use this module, you need to:

1. Go to Purchase > Orders > Requests for Quotation.
2. Create a new quotation with 2 units of a storable product.
3. Confirm quotation.
4. Click on Receipt Smart Button.
5. Receipt 1 unit, validate and create backorder.
6. Receipt the last unit from the backorder.
7. Check Effective and Commitment Date fields on Purchase Order Lines.
