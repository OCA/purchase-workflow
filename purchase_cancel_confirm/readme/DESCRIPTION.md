When the user clicks on the Cancel button of a purchase order, a
confirmation wizard is shown, where a cancellation reason can optionally
be given. The reason, the user and the date are then stored on the
purchase order.

It replaces the plain confirmation dialog of the standard Cancel
button of the list views, which asks for no reason.

The wizard is only shown when the cancellation is requested from the
Cancel button of the form or list views. Purchase orders cancelled by
other flows, such as merging requests for quotation or cancelling a
purchase agreement, are not affected.
