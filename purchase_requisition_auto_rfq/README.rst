Generate a draft request for quotation for each vendor from a confirmed
purchase template. Each quotation includes only the products the vendor
supplies.

**Table of contents**

.. contents::
   :local:

Usage
=====

- In Purchase, create a purchase agreement of type **Purchase
  Template**.
- Add products, quantities, and prices. Lines in red have no registered
  vendor for the product in the agreement's company.
- Confirm the agreement and click **Generate RFQs for suppliers**.
- Open **RFQs/Orders** to see the draft quotation for each vendor. Each
  quotation includes the agreement lines for products that vendor
  supplies. The agreement chatter lists products without a vendor.
- The RFQs use the agreement's buyer. If the field is blank, the RFQs
  use the user who generated them.
