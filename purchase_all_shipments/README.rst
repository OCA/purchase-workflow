With the core "purchase_stock" module, in a purchase order the "Receipt"
button lets the user see the pickings generated by the order itself.

With this module, that button is replaced by an "All Pickings" button
that also shows the pickings chained to them with push rules, such as
the internal transfers of a reception in two or three steps. Pickings of
other documents, like a delivery that uses the received goods, are not
listed.

This is consistent with the "sale" module, where from the sale order the
user can access the generated delivery and all chained ones.

The implementation follows the destination moves of the order's moves,
keeping only the ones created by push rules.
