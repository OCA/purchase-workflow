1. Go to *Purchase \> Orders \> Purchase Agreements* and create a
   blanket order.
2. On each line, set the *Lead Time* (in days) and the *Minimum
   Quantity* agreed with the vendor, next to the unit price.
3. Confirm the agreement. The vendor pricelist line created for each
   product carries those values.
4. Click *New Quotation*: the lines are planned for today plus the lead
   time. Purchase orders for the vendor that select the agreement's
   pricelist line are planned the same way.
