To use this module, you need to:

1.  Install the module.
2.  Open a purchase order via *Purchase \> Orders \> Purchase Orders*.
3.  In the *Order Lines* tab, the **Image** column will appear showing a
    thumbnail of each product.
4.  The column is optional by default; if it is not visible, click the
    column settings icon (⚙) at the right of the list header and enable
    **Image**.

Note: The image is taken from the product's thumbnail (128×128 px).
Products without an image configured will show an empty cell.
