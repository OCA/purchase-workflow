This module hide purchase prices in some specific conditions.

Current conditions are:

-  user must belong to ``Purchase hide prices`` group.
-  vendor partner ``Hide Prices`` field must be check.

Vendor children (aka contacts) attached to purchase order are supported.

Configuration
=============

The method ``_compute_hide_price`` in purchase.order model allows to
define conditions to hide prices.

Implement your own rules by overriding this method.
