**Usual process of Purchasing with Work Acceptance**

1.  Create a Purchase Order \> Work Acceptance
2.  Set Due Date on Work Acceptance
3.  It will calculate Late Days and Fines Amount automatic (adjustable)
4.  Accept the Work Acceptance
5.  Generate Fines Invoice by clicking "Create Fines Invoice" button,
    which includes the configured default account code.
6.  Normally process

**Create Fines from Work Acceptance**

1.  Go to Purchase \> Orders \> Work Acceptance
2.  In List View, Select all you have to create fines invoice \> Action
    \> Create Fines Invoice
3.  In Form View, Select work acceptance \> click Create Fines Invoice
    button

**Create Fines from Invoice**

1.  Go to Invoicing \> Customers \> Invoices \> Create
2.  Select Late WA (wa is delivery late)
3.  It will automatically generate lines.
